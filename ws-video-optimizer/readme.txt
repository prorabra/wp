Стискає відео з медіатеки у MP4 через FFmpeg без видимої втрати якості та видаляє оригінал, щоб він не займав місце на сервері.

== Description ==

Автор: Zaichenko Andrey — https://websites-service.com/

Що робить плагін:

* Після завантаження відео у фоні стискає його у MP4 (H.264 + AAC).
* Якість за замовчуванням CRF 23: різниці на екрані не видно, а файл значно менший. 18–20 дає майже повну відсутність втрат.
* Зменшує 4K до 1080p (налаштовується; 0 зберігає роздільність) і ніколи не збільшує відео.
* Додає faststart, щоб відео починало грати до повного завантаження.
* Видаляє оригінал після успішного стиснення й за потреби оновлює посилання в записах.
* Якщо стиснений файл більший за оригінал, оригінал залишається.
* Обробляє по одному відео з низьким пріоритетом процесора.
* Показує статус кожного відео та зекономлене місце, дозволяє поставити в чергу вже завантажені відео.

Налаштування: Медіафайли → Оптимізація відео.

Вимоги: FFmpeg на сервері та дозволена PHP-функція exec(). Інший шлях до FFmpeg задається у wp-config.php:
`define( 'WSVO_FFMPEG', '/path/to/ffmpeg' );`

WP-CLI:
`wp ws-video queue-all` — поставити всі необроблені відео в чергу.
`wp ws-video run` — обробити чергу зараз.

== Installation ==

1. Плагіни → Додати новий → Завантажити плагін → ws-video-optimizer.zip.
2. Активуйте плагін.
3. Відкрийте Медіафайли → Оптимізація відео й перевірте блок «Перевірка сервера».

== Frequently Asked Questions ==

= FFmpeg не знайдено =

Попросіть хостинг встановити FFmpeg або вкажіть шлях до нього в wp-config.php. На дешевому shared-хостингу FFmpeg часто недоступний.

= Великі відео лишаються зі статусом «Помилка: перервано» =

Хостинг обірвав довгий процес. Налаштуйте системний cron або обробляйте чергу командою `wp ws-video run`.
