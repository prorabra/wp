Стискає зображення, конвертує JPEG/PNG у WebP і видаляє оригінали, щоб вони не займали місце на сервері.

== Description ==

Автор: Zaichenko Andrey — https://websites-service.com/

Що робить плагін:

* Під час завантаження в медіатеку стискає зображення (якість за замовчуванням 82).
* За потреби конвертує JPEG і PNG у WebP, зберігаючи прозорість.
* Зменшує надто великі фото до заданої найбільшої сторони (за замовчуванням 2560 px).
* Видаляє оригінальний файл, тому на сервері лишається тільки оптимізована версія та її мініатюри.
* Якщо файл після стиснення не став меншим, залишає оригінал без змін.
* Пакетно обробляє вже завантажені зображення й оновлює посилання на них у записах, сторінках і даних конструкторів.
* GIF та SVG не змінює.

Налаштування: Медіафайли → Оптимізація зображень.

WP-CLI: `wp ws-image bulk`

== Installation ==

1. Плагіни → Додати новий → Завантажити плагін → ws-image-optimizer.zip.
2. Активуйте плагін.
3. Відкрийте Медіафайли → Оптимізація зображень.

== Frequently Asked Questions ==

= Чи можна повернути оригінали? =

Ні, вони видаляються. Перед пакетною обробкою зробіть резервну копію або вимкніть опцію «Видаляти оригінальні файли».

= Сервер не підтримує WebP =

Плагін покаже попередження й лише стискатиме файли в їхньому форматі. Попросіть хостинг увімкнути Imagick або GD з підтримкою WebP.
